# Petbot media

This folder contains the visual assets intentionally used by the current cinematic homepage:

- `petbot-cinematic-world.png` — hero and closing scene poster
- `petbot-hero-loop.mp4` — hero motion layer
- `petbot-tag-front.png` — product reveal, front
- `petbot-tag-back.png` — product reveal, reverse / QR
- `petbot-closing-pets.png` — closing homepage scene
- `petbot-upi-qr.jpeg` — customer-facing manual UPI QR; use only in checkout

The supplied reference images contain Pawfect marks. They were used only to study composition and interaction patterns; no Pawfect logo or mark is used in the Petbot experience.

An official Petbot logo/mark was not present among the supplied files. Until one is added here, the site intentionally uses a text wordmark rather than substituting another brand's asset.
